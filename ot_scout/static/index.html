Assessment report

Generates a .docx from the evidence currently in the database: cover, document control, executive readout, coverage, inventory, communications, auto-drafted observations, roadmap and appendices. Every observation is a draft that requires assessor validation.

Evidence package

One zip with the assessment JSON, the Word report (using the fields above), every CSV and the diagram, the raw PCAP of every live session, and a MANIFEST.txt listing every file with its SHA-256 — verify later with sha256sum -c SHA256SUMS. This is what to keep with the engagement record.

Evidence exports

The JSON export carries everything the report uses (sessions, assets, relationships, sites, findings, zones) and can be re-rendered offline with python3 -m ot_scout.report assessment.json report.docx.

Reset

Deletes every session, asset, relationship, site, finding and conduit decision in the current data set. The IEEE vendor table is kept.
