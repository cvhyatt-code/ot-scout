# OT Scout — Community Edition

Passive OT/ICS asset discovery for authorized assessments.

Connect OT Scout to a mirror port or network TAP and it builds an asset
inventory, a communications map, and a Purdue zone diagram from the traffic
it sees. It never transmits on the capture interface.
